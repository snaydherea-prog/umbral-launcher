TU COMUNIDAD

Administración

Prepara un modpack, revisa sus archivos y publica una versión para todos.

Cargando administración…

1. Preparar modpack

Importa un ZIP exportado de CurseForge o una carpeta preparada.

Tu importación aparecerá aquí.

Los mundos, capturas y datos de cuenta quedan fuera de la importación. Las opciones del jugador se conservan durante las actualizaciones.

Las descargas oficiales de CurseForge están pendientes de autorización para Umbral. Puedes importar y revisar el ZIP mientras tanto.

2. Publicar versión

Cuenta autorizada: snaydherea-prog. Usa un token limitado a umbral-launcher, con Contents: lectura y escritura. Se usa solo durante esta sesión.

Selecciona un borrador para revisar la publicación.

Los archivos que publiques serán públicos en GitHub. Publica contenido que puedas distribuir y conserva los créditos de sus autores.

Iniciar sesión con Microsoft

Se abrirá la página oficial de Microsoft. Inicia sesión allí y vuelve a Umbral.
